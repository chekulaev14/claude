# Инструкция: Добавление новых услуг (кластеров)

## Концепция

У нас есть 5 текущих кластеров услуг:
1. **mezhgorod** - Междугородние грузоперевозки
2. **transportnaya** - Услуги транспортной компании
3. **dlinnomer** - Длинномеры и шаланды
4. **po-rossii** - Грузоперевозки по России
5. **fura** - Перевозка фурой

Каждый кластер представлен на 48 городах → 240 страниц (5 × 48).

---

## Как добавить новый кластер

### Шаг 1: Подготовка контента

#### 1.1. Создать папку для SEO-текстов
```bash
mkdir -p seo-texts/spetstehnika
```

#### 1.2. Написать MD-файлы для каждого города
Формат: `seo-texts/spetstehnika/spetstehnika-{город}.md`

Пример: `seo-texts/spetstehnika/spetstehnika-moscow.md`
```markdown
# Перевозка спецтехники в Москве

Компания «Динамика» предлагает **перевозку спецтехники** по Москве и всей России...

## Виды спецтехники

Перевозим:
- **Экскаваторы** — гусеничные и колёсные
- **Бульдозеры** — Caterpillar, Komatsu, ЧТЗ
- **Погрузчики** — фронтальные и вилочные
...
```

**Важно:** Первый заголовок `#` — это H1 страницы.

---

### Шаг 2: Добавить кластер в скрипт

Открыть `generate_cluster_pages.py` и добавить новый кластер:

#### 2.1. В список CLUSTERS:
```python
CLUSTERS = ['mezhgorod', 'transportnaya', 'dlinnomer', 'po-rossii', 'fura', 'spetstehnika']
```

#### 2.2. В словарь CLUSTER_INFO:
```python
CLUSTER_INFO = {
    # ...существующие...
    'spetstehnika': {
        'title': 'Перевозка спецтехники',
        'description': 'Экскаваторы, бульдозеры, погрузчики по всей России',
        'icon': 'bi-truck'  # иконка Bootstrap Icons
    }
}
```

#### 2.3. В словарь CLUSTER_FAQ (опционально):
```python
CLUSTER_FAQ = {
    # ...существующие...
    'spetstehnika': [
        ('Какую спецтехнику перевозите?', 'Экскаваторы, бульдозеры, погрузчики...'),
        ('Нужны ли разрешения?', 'Для негабаритной техники оформляем разрешения...'),
        # ещё 3 вопроса
    ]
}
```

---

### Шаг 3: Добавить изображения

#### 3.1. Создать папку для картинок
```bash
mkdir -p assets/images/clusters/spetstehnika
```

#### 3.2. Добавить фото (минимум 10-15 шт)
Форматы: `.jpg`, `.jpeg`, `.png`, `.webp`

Примеры названий:
- `excavator-transport-1.jpg`
- `bulldozer-delivery-2.jpg`
- `loader-shipping-3.jpg`

**Важно:** Картинки будут выбираться автоматически и закрепляться за секциями через маппинг.

---

### Шаг 4: Генерация страниц

#### 4.1. Тестовая генерация (1 город)
```bash
python3 generate_cluster_pages.py --test --cluster spetstehnika
```

Проверить результат в `regions/balashikha/spetstehnika/index.html`

#### 4.2. Генерация для конкретного города
```bash
python3 generate_cluster_pages.py --city moscow --cluster spetstehnika
```

#### 4.3. Генерация для всех городов
```bash
python3 generate_cluster_pages.py --cluster spetstehnika
```

---

### Шаг 5: Проверка результата

1. **Проверить HTML-страницы:**
   - Title, H1, meta description правильные
   - Картинки загружаются
   - Перелинковка на другие кластеры работает

2. **Проверить маппинг картинок:**
   ```bash
   cat data/images-mapping.json
   ```

   Должна быть структура:
   ```json
   {
     "moscow": {
       "spetstehnika": {
         "Виды спецтехники": "/assets/images/clusters/spetstehnika/excavator-1.jpg",
         "Тарифы на перевозку": "/assets/images/clusters/spetstehnika/bulldozer-2.jpg"
       }
     }
   }
   ```

3. **Проверить локально:**
   Открыть `regions/moscow/spetstehnika/index.html` в браузере

## Система маппинга картинок

### Как это работает?

1. **При первой генерации:**
   - Скрипт случайно выбирает картинки для каждой секции
   - Сохраняет выбор в `data/images-mapping.json`

2. **При повторной генерации:**
   - Скрипт читает маппинг
   - Использует ТЕ ЖЕ картинки для тех же секций
   - Если появилась новая секция → выбирает для неё новую картинку

3. **Результат:**
   - Картинки стабильны при регенерации
   - SEO не страдает (URL картинок не меняются)
   - Google Images индексирует стабильные изображения

---

### Ручное редактирование маппинга

Если не нравится автоматически выбранная картинка:

1. Открыть `data/images-mapping.json`
2. Найти нужный город/кластер/секцию
3. Изменить путь к картинке:
   ```json
   {
     "moscow": {
       "spetstehnika": {
         "Виды спецтехники": "/assets/images/clusters/spetstehnika/better-image.jpg"
       }
     }
   }
   ```
4. Перегенерировать страницу:
   ```bash
   python3 generate_cluster_pages.py --city moscow --cluster spetstehnika
   ```

---

### Сброс маппинга

**Для одного города:**
Удалить запись из JSON:
```json
{
  "moscow": {
    // удалить "spetstehnika": {...}
  }
}
```

**Для всех городов:**
Удалить весь кластер из всех городов в JSON.

**Полный сброс:**
```bash
rm data/images-mapping.json
```

## Обновление существующих страниц

### Сценарий: Добавили новый кластер, нужно обновить перелинковку

**Проблема:** На старых страницах (mezhgorod, fura и т.д.) нет ссылки на новый кластер.

**Решение:**

1. Добавить новый кластер в `CLUSTER_INFO` (см. Шаг 2.2)

2. Перегенерировать ВСЕ страницы:
   ```bash
   python3 generate_cluster_pages.py
   ```

3. Что изменится:
   - ✅ Блок "Другие услуги" — добавится новая карточка
   - ✅ Title, H1, контент — останутся прежними
   - ✅ Картинки — останутся прежними (благодаря маппингу)

4. Проверить diff в Git:
   ```bash
   git diff regions/moscow/mezhgorod/index.html
   ```

   Должны измениться только строки с блоком "Другие услуги".

## Частые вопросы

### 1. Сколько MD-файлов нужно написать?

**48 файлов** — по одному на каждый город.

Список городов смотри в `generate_cluster_pages.py` → `CITIES`.

---

### 2. Можно ли использовать один MD-файл для всех городов?

Нет, каждый город = уникальный текст для SEO.

Но можно использовать шаблон и вставлять переменные:
- `{город}` → Москва, Казань и т.д.
- Потом через скрипт заменить.

---

### 3. Что если у меня нет 48 SEO-текстов?

Варианты:
1. Сгенерировать для части городов (например, топ-10)
2. Использовать ChatGPT/Claude для генерации текстов
3. Написать базовый шаблон и адаптировать под каждый город

---

### 4. Можно ли добавить кластер только для 1 города?

Да, просто создать MD-файл только для этого города:
```bash
# Только для Москвы
touch seo-texts/spetstehnika/spetstehnika-moscow.md
python3 generate_cluster_pages.py --city moscow --cluster spetstehnika
```

---

### 5. Как изменить FAQ для кластера?

Отредактировать `CLUSTER_FAQ` в `generate_cluster_pages.py`:
```python
CLUSTER_FAQ = {
    'spetstehnika': [
        ('Вопрос 1?', 'Ответ 1'),
        ('Вопрос 2?', 'Ответ 2'),
        # ...5 вопросов
    ]
}
```

Перегенерировать страницы.

---

### 6. Картинки меняются при каждой генерации!

Проверь, что:
1. Файл `data/images-mapping.json` существует
2. Скрипт имеет права на запись в папку `data/`
3. Пути к картинкам в маппинге правильные

### Переменные в шаблоне

В MD-файлах можно использовать переменные (подставляются автоматически):

- `{{CITY_NAME_RU}}` → Москва
- `{{CITY_NAME_GENITIVE}}` → Москвы
- `{{CITY_NAME_PREPOSITIONAL}}` → Москве

Пример:
```markdown
# Перевозка спецтехники в {{CITY_NAME_PREPOSITIONAL}}

Работаем в {{CITY_NAME_PREPOSITIONAL}} с 2018 года...
```

**Важно:** H1 обрабатывается автоматически — "в Москве" заменяется на "Москва".
