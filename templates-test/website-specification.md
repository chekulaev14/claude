# Техническое задание: Альтернативная версия сайта ТК "Динамика"

## Анализ текущего сайта

### Структура проекта
- **Основная страница**: `index.html`
- **Калькулятор**: `calculator-new.html`
- **Страницы услуг**: `pages/` директория
- **Шаблоны**: `templates/` (header, footer, layout)
- **Стили**: `assets/css/styles.css`
- **JavaScript**: `assets/js/script.js`, `assets/js/template-loader.js`

### Текущая структура сайта

#### 1. **Главная страница (index.html)**
**Секции:**
- **Header** - навигационное меню с логотипом, услуги, цены, клиенты, маршруты, контакты
- **Contact Form Section** - форма быстрого заказа:
  - Заголовок: "Быстро расчитаем, быстро привезем"
  - Подзаголовок: "От газели до фуры, от 100 кг до 20 тонн, догрузом или отдельной машиной!"
  - Форма в одну строку: телефон, откуда, куда, дата, кнопка "Отправить заявку"
  - Ссылка на подробную форму калькулятора
- **Statistics Section** - блок с достижениями:
  - "Более 850 клиентов за 7 лет работы"
  - "Выполнено более 3500 рейсов по всей России"
  - Кнопка "Ознакомиться" → clients.html
- **Services Section** - карусель услуг (Swiper):
  - 4 карточки услуг с эмодзи-иконками
  - Каждая содержит: тип кузова, длину, грузоподъемность
  - Кнопка "Перейти" на соответствующую страницу услуги

#### 2. **Навигационное меню (header.html)**
- Логотип компании
- Выпадающее меню "Услуги":
  - ГРУЗОПЕРЕВОЗКИ МЕЖГОРОД
  - ГРУЗОПЕРЕВОЗКИ ФУРА
  - ГРУЗОПЕРЕВОЗКИ ДЛИННОМЕР ШАЛАНДА
  - ГРУЗОПЕРЕВОЗКИ ДОГРУЗ ПОПУТНО
- Ценообразование
- Клиенты
- Маршруты
- Контакты
- Кнопка "Заказать" с телефоном

#### 3. **Страницы услуг**
- `pages/intercity.html` - межгород
- `pages/truck.html` - фура
- `pages/long-trailer.html` - длинномер/шаланда
- `pages/partial.html` - догруз/попутно

#### 4. **Страница цен (prices.html)**
- Заголовок: "Прозрачная фиксированная комиссия"
- 2 тарифных плана:
  - **Без НДС**: 5000₽ + 1% от стоимости перевозки
  - **С НДС**: 6000₽ + 1.5% от стоимости перевозки
- Описание честности работы с клиентами

#### 5. **Страница контактов (contacts.html)**
**Секции:**
- **Контактная информация**:
  - Карточка с двумя ООО: "Динамика" без НДС, "Динамика Плюс" с НДС
  - Адрес: г. Тольятти, ул. Ленина, 44 к3
  - Телефон: 8-987-416-51-87
- **Способы связи**: звонок, Telegram, WhatsApp
- **Время работы**:
  - Прием новых заявок: 7 дней в неделю с 9:00 до 20:00
  - Заявки в работе: 24/7
- **Google Maps** с офисом на карте

#### 6. **Калькулятор (calculator-new.html)**
- Многошаговая форма расчета стоимости
- Google Maps интеграция
- Автодополнение городов
- Различные типы транспорта
- Расчет с/без НДС
- Модальные окна для заказа

### Технические особенности
- **Фреймворк**: Bootstrap 5.3
- **Иконки**: Bootstrap Icons, Font Awesome
- **Карусель**: Swiper.js
- **Карты**: Google Maps API
- **Шрифт**: Inter (Google Fonts)
- **Архитектура**: Модульная с template-loader.js для подгрузки header/footer
