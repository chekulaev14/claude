- **Решение**:
  1. Выполнили `npm install` в папке `mcp-servers/`
  2. Выполнили `npm run build` для компиляции TypeScript
- **Результат**: ✅ Сервер работает, статус "Connected"

- **Действие**: Очистили `.mcp.json` от лишних серверов

- **Оставлено**: sequential-thinking, playwright
- **Результат**: ✅ Конфигурация упрощена
