# PRD: Веб-сайт Динамика Карго
## Описание проекта
Создание профессионального веб-сайта для компании грузовых перевозок "Динамика Карго" на основе дизайна dinamika-cargo.ru.

## Цели проекта
1. Представить услуги компании грузовых перевозок
2. Обеспечить удобную форму для заявок клиентов
3. Создать адаптивный дизайн для всех устройств
4. Оптимизировать для поисковых систем (SEO)

## Технические требования

### Основная структура
- HTML5 семантическая разметка
- CSS3 с современными возможностями (Grid, Flexbox)
- Vanilla JavaScript для интерактивности
- Адаптивный дизайн (мобильная версия)
- Кроссбраузерная совместимость

### Дизайн-требования компактности
- **Компактная верстка**: Элементы не должны занимать избыточное пространство
- **Оптимизация шапки**: Меню должно быть минимальной высоты
- **Умная фиксация при скролле**: При прокрутке показывать только тонкую плашку вместо полной шапки
- **Сжатые отступы**: Уменьшить padding и margin у всех секций
- **Компактные карточки**: Оптимизировать размеры блоков услуг и преимуществ

### Секции сайта
1. **Шапка (Header)**
   - Логотип компании "Динамика Карго"
   - Контактная информация (телефон, email, время работы)
   - Навигационное меню с выпадающими подменю
   - Мобильное гамбургер-меню

2. **Hero секция**
   - Заголовок "Надежные грузовые перевозки"
   - Описание услуг компании
   - Ключевые показатели (24/7, до 20 тонн, до 16 м)
   - Призыв к действию "Оставить заявку"

3. **Блок услуг**
   - 4 карточки услуг:
     * Междугородние перевозки
     * Грузовые перевозки
     * Длинномерные перевозки
     * Сборные грузы
   - Иконки для каждой услуги
   - Описание и список преимуществ

4. **Преимущества компании**
   - 4 блока с преимуществами:
     * Опыт работы
     * Надежность
     * Выгодные цены
     * Круглосуточная поддержка
   - Нумерация и описание

5. **Контактная форма**
   - Поля: имя, телефон, email, услуга, описание
   - Валидация полей
   - Блок с контактной информацией
   - Обработка отправки формы

6. **Подвал (Footer)**
   - Информация о компании
   - Ссылки на услуги
   - Контактные данные
   - Копирайт

### Функциональность JavaScript
- Мобильное меню (гамбургер)
- Плавная прокрутка к якорям
- Валидация контактной формы
- Форматирование номера телефона
- Анимации при прокрутке страницы
- Изменение фона шапки при скролле

### Цветовая схема и дизайн
- Основной цвет: #2c5aa0 (синий)
- Акцент: #ff6b35 (оранжевый)
- Фон: белый и #f8f9fa (светло-серый)
- Шрифт: Inter (Google Fonts)
- Профессиональный стиль в тематике логистики
