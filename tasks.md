**Описание:** Разработать универсальный HTML шаблон, который можно использовать для всех контентных страниц (услуги, цены, клиенты, маршруты, портфолио, контакты).
**Требования:**
- Использовать существующую архитектуру проекта (Bootstrap 5.3.2)
- Модульная структура с подключением header/footer из templates/
- Адаптивная верстка
- Готовые блоки для различных типов контента (текст, карточки, списки)
- Место для SEO-блоков
**Файл:** `templates/content-page-template.html`
**Статус:** ✅ Выполнено

## Задача 1.3: Создать контент для страниц услуг

**Описание:** Разработать текстовый контент для всех страниц услуг на основе универсального шаблона content-page-template.html.

**Требования:**
- Создать контент для 4 основных услуг:

  - Грузоперевозки фура

  - Грузоперевозки догруз/попутно

- SEO-оптимизированные тексты с ключевыми словами
- Уникальный контент для каждой услуги
- Конкретные технические характеристики

**Файлы:** Контент-план для `pages/intercity.html`, `pages/truck.html`, `pages/long-trailer.html`, `pages/partial.html`

**Статус:** ⏳ Ожидает выполнения

## Общие принципы

**Технологии:**
- HTML5 + Bootstrap 5.3.2
- Vanilla JavaScript
- Swiper.js для каруселей
- Google Maps API
- Шрифт: Inter (Google Fonts)

**Архитектура:**
- Модульная структура (header/footer в templates/)
- CSS и JS в папке assets/
- Страницы в папке pages/
- Адаптивная верстка для всех устройств

**UX принципы:**
- Прозрачное ценообразование
- Быстрая обратная связь
- Минимум полей в формах
- Мобильная адаптивность
