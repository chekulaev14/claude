# Система управления клиентами

## Обзор системы

Система управления клиентами предназначена для отображения клиентской базы компании ТК "Динамика" в удобном интерактивном формате на веб-странице.

### Основные функции:
- Отображение всех клиентов компании (880 организаций)
- Фильтрация по алфавиту (русские буквы А-Я)
- Пагинация (20 клиентов на страницу)
- Адаптивное отображение на всех устройствах
- Статистика и навигация

## Структура данных

### Источник данных: `assets/data/clients.json`

```json
[
  {
    "name": "Название организации",
    "inn": "1234567890"
  }
]
```

### Характеристики базы данных:
- **Общее количество записей:** 880 клиентов
- **Формат ИНН:** строка из 10-12 цифр
- **Кодировка:** UTF-8 (поддержка кириллицы)
- **Размер файла:** ~52 КБ

### Процесс создания базы:
1. **Исходный файл:** `sheet.xlsx` - Excel файл с клиентской базой
2. **Конверсия:** `convert_excel.py` - Python скрипт для преобразования
3. **Очистка данных:** автоматическая обрезка пробелов и форматирование ИНН
4. **Валидация:** проверка структуры и целостности данных

## Детальное описание компонентов

### ClientsManager класс

```javascript
class ClientsManager {
    constructor() {
        this.clients = [];           // Все клиенты из JSON
        this.filteredClients = [];   // Отфильтрованные клиенты
        this.currentPage = 1;        // Текущая страница
        this.itemsPerPage = 20;      // Клиентов на странице
        this.selectedLetter = '';    // Выбранная буква фильтра
    }
}
```

### Основные методы:

#### `async init()`
- Инициализация системы
- Загрузка данных
- Настройка обработчиков событий
- Создание алфавитной навигации
- Первичная отрисовка

#### `async loadClients()`
- Загрузка данных из `assets/data/clients.json`
- Очистка данных (обрезка пробелов, форматирование ИНН)
- Обработка ошибок загрузки
- Копирование в `filteredClients`

#### `createAlphabetNavigation()`
- Создание кнопок алфавитной навигации
- Кнопка "Все" + 33 русские буквы (А-Я)
- Настройка обработчиков кликов
- Bootstrap стилизация кнопок

#### `filterByLetter(letter)`
- Фильтрация клиентов по первой букве названия
- Обновление активной кнопки в навигации
- Сброс на первую страницу
- Вызов перерисовки списка

#### `applyFilters()`
- Применение всех активных фильтров
- Обновление `filteredClients` массива
- Сброс пагинации на первую страницу
- Вызов отрисовки результатов

#### `renderClients()`
- Отрисовка карточек клиентов для текущей страницы
- Расчет диапазона отображения (startIndex, endIndex)
- Создание HTML карточек через `createClientCard()`
- Обновление статистики и пагинации

#### `createClientCard(client, index)`
- Создание HTML разметки для одной карточки клиента
- Bootstrap классы для адаптивности
- Отображение номера, ИНН и названия
- Возврат готового DOM элемента

#### `updateStatistics()`
- Обновление панели статистики
- Общее количество клиентов
- Количество показанных после фильтрации
- Информация о текущей странице

#### `renderPagination()`
- Создание элементов пагинации
- Кнопки "Предыдущая"/"Следующая"
- Номера страниц (текущая ±2)
- Обработчики переходов между страницами

#### `showError(message)`
- Отображение сообщений об ошибках
- Скрытие спиннера загрузки
- Bootstrap alert компонент для ошибок

**Логика отображения:**

- Кнопки "Предыдущая"/"Следующая" появляются по необходимости
- Активная страница выделяется классом `.active`
- При клике происходит плавная прокрутка наверх

## Производительность и оптимизация

### Загрузка данных:
- **Размер JSON:** ~52 КБ (880 записей)
- **Время загрузки:** ~100-200мс
- **Кэширование:** браузерное кэширование JSON файла
- **Обработка ошибок:** graceful degradation при недоступности данных

### Отрисовка:
- **Виртуализация:** 20 элементов на страницу (вместо 880)
- **Lazy loading:** загрузка только видимых элементов
- **DOM манипуляции:** минимизированы через batch операции
- **Память:** эффективное управление DOM элементами

### Адаптивность:
- **Mobile first:** оптимизация для мобильных устройств
- **Touch friendly:** крупные кнопки для тач-интерфейса
- **Viewport optimization:** корректная работа на всех размерах экрана

## Документация API

### ClientsManager API:

```javascript
// Инициализация
const manager = new ClientsManager();

// Публичные методы
manager.filterByLetter('А');  // Фильтр по букве А

// Свойства только для чтения

manager.filteredClients.length // Количество после фильтрации
```
