## Информационные страницы

### Клиенты - `pages/clients.html`

**URL:** `/pages/clients.html`  
**Назначение:** Демонстрация клиентской базы и повышение доверия к компании

**Содержание страницы:**
- Заголовок "Наши клиенты" + подзаголовок "Более 880 партнеров доверяют нам свои грузоперевозки"
- Алфавитная навигация по русским буквам (А-Я) + кнопка "Все"
- Статистика: общее количество клиентов, показанные клиенты, номер страницы
- Карточки клиентов с названием и ИНН (20 клиентов на страницу)
- Пагинация для навигации по страницам

**Функциональность:**
- Загрузка данных из `assets/data/clients.json` (880 клиентов)
- Фильтрация клиентов по первой букве названия
- Пагинация с плавной прокруткой наверх при переходе между страницами
- Адаптивная сетка карточек (3 колонки на десктопе, 2 на планшете, 1 на мобильном)
- Автоматическая очистка данных (обрезка пробелов, форматирование ИНН)

**Технические особенности:**
- JavaScript класс `ClientsManager` для управления функциональностью
- Bootstrap 5.3 для стилизации и адаптивности
- Локализация на русском языке (включая алфавитную навигацию)
- Обработка ошибок при загрузке данных
- Спиннер загрузки и сообщения об ошибках

**Целевая аудитория:** Потенциальные клиенты для повышения доверия к компании

## Связи между страницами

### Основные пути пользователя:
1. **Главная → Услуга → Контакты** (основной conversion path)
2. **Главная → О компании → Услуги** (изучение компании)
3. **Услуга → Калькулятор → Заявка** (планируемый path)

### Внутренние ссылки:
- Все страницы услуг ссылаются друг на друга
- Из каждой услуги есть ссылка на контакты
- Footer содержит ссылки на все основные страницы
