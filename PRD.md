# Product Requirements Document (PRD)

**Проект:** Сайт экспедиторской компании «Динамика»
**URL:** https://dinamika-cargo.ru
**Тип:** Маркетинговый сайт (статический HTML + Bootstrap)
**Хостинг:** GitHub Pages (ветка main-secure)
**Обновлено:** Январь 2026

---

## 1. Цель продукта

Привлечение клиентов через **Яндекс Директ** и **SEO** в экспедиторскую компанию «Динамика».

---

## 2. Целевая аудитория

**НЕ наша ЦА:** Крупные компании с ежедневными перевозками и штатными логистами.

**Наша ЦА:**
* Компании с регулярными, но не ежедневными перевозками (строительные организации, временные проекты)
* Небольшие предприниматели без логиста — нужна перевозка быстро, без звонков

**Потребности:**
* Оперативность ответа
* Прозрачная цена (закупка + комиссия)
* Минимум звонков и переговоров

**География:** 48 городов (17 крупных + 31 Подмосковье)

---

## 3. USP (Уникальное торговое предложение)

* **Прозрачное ценообразование:** клиент видит закупочную цену и наценку
* **Фиксированная комиссия:**
  * Без НДС: 5000₽ + 1%
  * С НДС: 6000₽ + 1.5%

---

## 4. Текущая функциональность

* Форма "Оставить заявку" (имя, телефон, маршрут, дата)
* Калькулятор стоимости перевозки
* Telegram-бот @dinamikus_bot для быстрых заявок
* Адаптивная вёрстка (desktop/tablet/mobile)
* SEO-структура: 48 городов × 20 кластеров + 1264 маршрута

---

---

## 6. Технический стек

**Фронтенд:**
- HTML5 + Bootstrap 5.3.2
- Шрифт: IBM Plex Sans (Google Fonts)
- CSS: кастомные стили поверх Bootstrap

**Интерактивность:**
- Vanilla JavaScript
- Swiper.js для каруселей
- Яндекс.Карты API

**Формы:**
- HTML формы с валидацией
- Отправка через fetch API
- Email через Formspree

**Шаблонизация:**
- template-loader.js для header/footer
- Python скрипты для генерации страниц

**SEO:**
- Schema.org разметка на всех страницах
- Canonical теги
- sitemap.xml (2300+ URL)
- robots.txt
