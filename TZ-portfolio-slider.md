# ТЗ: Слайдер проектов на Swiper.js

## Цель
Заменить Bootstrap Carousel на Swiper.js для карточек проектов на странице portfolio.html

## Технические требования

### Библиотека
- **Swiper.js** (уже используется в проекте на главной странице)
- Версия: последняя стабильная (проверить в index.html какая подключена)

### Общие требования к слайдеру

1. **Одинаковая высота карточек**
   - Все карточки должны иметь одинаковую высоту
   - Высота определяется по самой высокой карточке
   - При изменении размера окна высота пересчитывается

2. **Адаптивность**
   - Desktop (>992px): показывать 1 карточку
   - Tablet (768-991px): показывать 1 карточку
   - Mobile (<768px): показывать 1 карточку

3. **Навигация**
   - Стрелки влево/вправо (только на desktop)
   - Свайп (touch) на мобильных и планшетах
   - Пагинация (точки) внизу слайдера

4. **Анимация**
   - Плавный переход между слайдами
   - Скорость: 300-400ms

## Структура карточки

Каждая карточка состоит из:

```
┌─────────────────────────────────────────────┐
│ ┌─────────┐  ┌──────────────────────────┐  │
│ │         │  │ Заголовок         [Бадж] │  │
│ │  Фото   │  │ Описание                 │  │
│ │         │  │                          │  │
│ │         │  │ 📍 Маршрут 1             │  │
│ │         │  │ 📍 Маршрут 2             │  │
│ │         │  │ 📍 Маршрут 3 (если есть) │  │
│ │         │  │                          │  │
│ └─────────┘  │ Рейсов: XX               │  │
│              │ [Кнопка Подробнее]       │  │
│              └──────────────────────────┘  │
└─────────────────────────────────────────────┘
```

### Детали макета:

**Карточка:**
- Bootstrap card: `border-0 shadow-lg overflow-hidden`
- Максимальная ширина: 800px
- Центрирование: `margin: 0 auto`

**Layout:**
- Desktop: 2 колонки (5/7 grid)
  - Левая колонка (col-md-5): Изображение
  - Правая колонка (col-md-7): Контент
- Mobile: 1 колонка (изображение сверху, контент снизу)

**Изображение:**
- Ширина: 100%
- Min-height: 300px
- Object-fit: cover
- НЕ использовать height: 100% (проблемы в Safari)

**Card-body:**
- Padding: p-4 (1.5rem)
- Display: d-flex flex-column
- НЕ использовать h-100 (проблемы с высотой)
- Кнопка внизу: mt-auto на обертке кнопки

**Заголовок:**
- H4
- Класс: card-title mb-0
- В одной строке с баджем: d-flex align-items-center mb-3

**Бадж:**
- Bootstrap badge: bg-success ms-2
- Текст: "Завершен"

**Описание:**
- Параграф с классом: card-text text-muted mb-4

**Маршруты:**
- Иконка: Bootstrap Icons `bi-geo-alt text-primary me-2`
- Отступ между маршрутами: mb-2
- Если есть количество рейсов на маршруте: justify-content-between

**Количество рейсов:**
- Small текст: text-muted
- Число: strong с ms-2
- Отступ снизу: mb-3 (НЕ mb-4!)

**Кнопка:**
- Bootstrap button: btn btn-primary w-100
- Текст: "Подробнее"

## Настройки Swiper.js

```javascript
new Swiper('.projects-swiper', {
  slidesPerView: 1,
  spaceBetween: 30,

  // Одинаковая высота
  autoHeight: false, // Отключаем автовысоту

  // Навигация
  navigation: {
    nextEl: '.swiper-button-next',
    prevEl: '.swiper-button-prev',
  },

  // Пагинация
  pagination: {
    el: '.swiper-pagination',
    clickable: true,
  },

  // Touch
  grabCursor: true,

  // Скорость
  speed: 400,

  // Адаптивность
  breakpoints: {
    0: {
      navigation: false, // Скрываем стрелки на мобильных
    },
    992: {
      navigation: true, // Показываем стрелки на desktop
    }
  }
});
```

  height: 100%;
}

/* Изображение адаптируется */

  display: flex;
}

.projects-swiper .col-md-5 img {

  width: 100%;
}
