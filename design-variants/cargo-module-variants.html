Сравнение вариантов

Вариант Плюсы Минусы Рекомендация
1. Карточки с иконками Согласуется с дизайном, информативно Занимает много места Для страниц городов
2. Горизонтальные Компактнее, читаемо Не помещается 5 в ряд Для страниц кластеров
3. Теги Очень компактно, мобильно Менее заметно Если много кластеров
4. Градиентные Привлекает внимание Может отвлекать от контента Для промо-блока
5. Сетка Максимально компактно Без описаний Когда нужна экономия места
