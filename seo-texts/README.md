## Логика работы

### Процесс создания текстов

1. **Пользователь пишет тексты** для одного кластера (например, "межгород")
2. **Пользователь присылает текст** в чат (копипаст или скриншот)
3. **Claude складывает текст** в соответствующую папку:
   - Определяет кластер (межгород, транспортная, и т.д.)
   - Определяет город (из названия файла или содержания)
   - Создаёт файл `[кластер]-[город].md` в папке `/seo-texts/[кластер]/`
4. **Claude отмечает прогресс** в файле `TZ-[кластер]-content.md`
5. **После завершения кластера** → переход к следующему

### Порядок работы с кластерами

**Приоритет кластеров:**
1. ⏳ **mezhgorod** (междугородние перевозки) — 14 фраз, 48 городов

Каждый файл должен содержать:

```markdown

[Текст 350-450 слов с использованием ключевых фраз]

## Блок 4: Дополнительная информация (cluster-extra)

- [x] ключевая фраза 1
- [x] ключевая фраза 2
- [x] ...
```

## Workflow Claude

Когда пользователь присылает текст, Claude:

1. ✅ Определяет кластер и город из текста
2. ✅ Проверяет наличие всех обязательных ключевых фраз
3. ✅ Создаёт/обновляет файл в нужной папке
4. ✅ Отмечает выполнение в файле `TZ-[кластер]-content.md`
5. ✅ Обновляет эту таблицу статуса
6. ✅ Сообщает пользователю: "Текст сохранён: /seo-texts/[кластер]/[файл].md"
