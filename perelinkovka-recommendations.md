### Структура сайта:
- **48** городских страниц (city/index.html)
- **961** страниц кластеров и cargo-типов
- **1265** страниц маршрутов
- **6** служебных страниц (contacts, faq, portfolio, clients, clients-map, thank-you)
- **4** страницы отдельных проектов (projects/project-001 до 005)

**Итого:** ~2284 страницы

### Меню навигации (templates/header.html):
- Клиенты → Список клиентов (/clients/), География клиентов (/clients-map/)
- Регионы → Все регионы (/regions/) + 48 городов
- Выполненные работы (/portfolio/)
- Ответы на вопросы (/faq/)
- Контакты (/contacts/)

### Основные проблемы:
1. ❌ Главная страница имеет только 1 внутреннюю ссылку
2. ❌ Страницы маршрутов почти изолированы (3 ссылки)
3. ❌ Служебные страницы изолированы (portfolio: 5 ссылок, clients: 3 ссылки)
4. ❌ Отсутствует footer-меню с навигацией
5. ❌ Нет перекрестных ссылок между городами
6. ❌ Страницы проектов не ссылаются на релевантные города/маршруты
7. ⚠️ Нет блока "Похожие маршруты" на страницах маршрутов
8. ⚠️ Portfolio не ссылается на релевантные cargo-страницы

### 🟡 Высокий приоритет

#### 4. Страницы маршрутов — блок "Похожие маршруты"

**Текущая ситуация:** На странице маршрута только 3 ссылки (главная, /routes/, обратный маршрут)
**Решение:** Добавить блок с 6 похожими маршрутами

**Макет:**

```html
<section class="similar-routes py-5 bg-light">
  <div class="container">
    <h2 class="mb-4">Похожие маршруты</h2>
    <div class="row g-3">
      <!-- 6 карточек маршрутов -->
      <div class="col-md-4">
        <a href="/routes/balashikha-nizhny-novgorod/" class="route-card-small">
          Балашиха → Нижний Новгород
          <span class="price">от 15 230 ₽</span>
        </a>
      </div>
      <!-- ... еще 5 -->
    </div>
  </div>
</section>
```

**Логика подбора похожих маршрутов:**

Для маршрута "Балашиха → Казань":

1. **2 маршрута из того же города-отправления:**
   - Балашиха → Нижний Новгород
   - Балашиха → Самара

2. **2 маршрута из соседних городов Подмосковья** (если отправление — Подмосковье):
   - Мытищи → Казань (соседний город)
   - Королёв → Казань (соседний город)

3. **2 маршрута в то же направление из других городов:**
   - Москва → Казань
   - Подольск → Казань

**Реализация:**

1. Создать файл `/data/similar-routes-mapping.json`:

```json
{
  "balashikha-kazan": [
    "balashikha-nizhny-novgorod",
    "balashikha-samara",
    "mytishchi-kazan",
    "korolev-kazan",
    "moskva-kazan",
    "podolsk-kazan"
  ],
  ...
}
```

2. Обновить `templates/route-template.html` — добавить плейсхолдер `{{SIMILAR_ROUTES}}`

3. Обновить `generate_route_pages.py` — генерировать блок похожих маршрутов

**Эффект:**
- +6 ссылок × 1265 страниц маршрутов = **~7500 новых связей**
- Снижение показателя отказов на страницах маршрутов
- Улучшение индексации маршрутов

**Файлы для изменения:**
- `templates/route-template.html`
- `generate_route_pages.py`
- Создать `data/similar-routes-mapping.json`

**Сложность:** Высокая (нужна логика генерации)
**Время:** 3-4 часа
**Приоритет:** 🟡 Высокий

### 2. Генерация похожих маршрутов

**Алгоритм:**

```python
def get_similar_routes(from_city, to_city, cities_data, routes_list):
    similar = []

    # 1. Два маршрута из того же города-отправления
    same_from = [r for r in routes_list if r['from'] == from_city and r['to'] != to_city]
    similar.extend(random.sample(same_from, min(2, len(same_from))))

    # 2. Два маршрута из соседних городов (если Подмосковье)
    if is_moscow_region(from_city):
        nearby = get_nearby_cities(from_city)
        nearby_routes = [r for r in routes_list if r['from'] in nearby and r['to'] == to_city]
        similar.extend(random.sample(nearby_routes, min(2, len(nearby_routes))))

    # 3. Два маршрута в то же направление
    same_to = [r for r in routes_list if r['to'] == to_city and r['from'] != from_city]
    similar.extend(random.sample(same_to, min(2, len(same_to))))

    return similar[:6]
```
